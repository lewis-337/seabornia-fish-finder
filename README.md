# Seabornia Fish Finder | iPhone / Mac

[アプリを開く](https://lewis-337.github.io/seabornia-fish-finder/)

シーボニア発の釣行向けPWAです。日本語の魚種図鑑、公開釣果、海底ガイド、端末内のポイント・釣果記録をまとめています。iPhoneではSafariで開き、共有メニューから「ホーム画面に追加」を選べます。

## 地図と操作

- 1本指で移動、2本指のピンチで拡大・縮小。ダブルタップ、＋／−、全体表示にも対応しています。
- 「海域を探す」から10海域を選べます。番号のタップでも詳細が開きます。詳細上端のハンドルで展開・縮小、×で閉じます。
- 「レイヤー」から釣り場、底質ガイド、GEBCO海底陰影を切り替えます。凡例もこのパネルにあります。
- 「ポイントを追加」で地図をタップすると仮のピンが表示されます。名前を入力して確定するまで保存されません。ピンチやドラッグでは保存しません。
- GPSでは推定精度も表示します。位置情報の許可がない場合は緯度・経度で手動登録できます。
- 地図・公開釣果の位置は海域の**概略代表位置**です。実測の釣果GPS地点や航路ではありません。距離は直線参考値です。

## 魚種・釣果・写真

47項目を名前、地形、釣り方で検索できます。魚種グループ、イカ、選択月で絞り込めます。年・月は端末に記憶し、初回は現在の月になります。「最近の釣果」「月別の釣果」で表示を切り替え、海域から開いた一覧はその海域だけに絞り込みます。

写真は出典・再利用ライセンスを確認し、デコードした実在の参考写真です。各詳細に撮影者、ライセンス、縮小／JPEG変換を表示しています。参考写真と現地釣果写真は区別しています。写真をタップすると拡大画面が開き、ピンチ、移動、拡大／縮小ボタン、全体表示を使えます。写真の一括診断は図鑑の末尾「写真・出典について」にあります。

GEBCO画像は広域の海底地形モデルです。**砂地・岩礁の実測結果や航海図ではありません。** 通信に失敗しても概略地図を使え、再読み込みできます。

## 海況・移動時間

4番目の「海況」で海域・釣行日・時刻を選び、風速／風向、突風、有義波高／周期、雨、日の出／日の入りを確認できます。日付は図鑑の月フィルターと別です。「船速を設定」で巡航速度を保存すると、海域一覧・詳細・保存ポイントに直線移動の目安を5分刻みで表示します。出発日と時刻を入れると到着目安も表示します。港内減速、迂回、風波を加味した航路案内ではありません。

潮汐は[tide736](https://tide736.net/)の油壺（pc=14/hc=16）の推算です。日別の潮名、上げ下げ、次の満干潮と動かせる曲線を表示します。潮位変化と実際の潮流は異なり、満干潮を測定された潮止まりとは扱いません。風・波は[Open-Meteo Weather](https://open-meteo.com/en/docs)／[Marine](https://open-meteo.com/en/docs/marine-weather-api)（CC BY 4.0）の地域予報です。取得時刻と対象日時、遅延・期限切れ・欠測を表示します。現地観測や出港可否の判定ではありません。気象庁の海上警報へのリンクもあります。

帰港予定は日付と時刻を設定できます。残り時間を表示し、15分前からアプリを開いている間にお知らせします。バックグラウンド通知はありません。海底ガイド・お気に入り・釣果更新は海況の末尾で展開できます。

「釣果 → 条件別」は公開報告と個人記録を分け、魚種・日付で絞り込めます。公開報告は釣れた時刻が不明なので、その日の油壺の参考潮汐だけを添えています。個人記録は時刻を任意で入力すると、その時点で利用できた推算と予報を出典付きで保存します。古い記録への時刻・過去天気の補完はしません。数量は原文どおりで、成功率や最も釣れる潮の順位は算出しません。

## 自分の記録とオフライン

ポイント、釣果、圧縮写真、お気に入りは端末内に保存します。クラウド同期はありません。JSONバックアップv5／読み込み（v4互換）、時刻を含む釣果CSVに対応します。v5は船速・釣行設定と条件スナップショットも保存します。読み込みは現在の記録を置き換えるため、確認画面を表示します。ブラウザデータを消す前にバックアップしてください。

初回のオンライン読み込みとキャッシュ準備が完了すると、アプリ、公開釣果履歴、47枚の魚種写真、取得済みの海況・潮汐をオフラインでも使えます。GPSの利用可否は端末の状況に依存し、GEBCOの未取得画像や外部出典には通信が必要です。保存済み履歴の表示と、収集の最終成功日時を区別しています。

## 更新・開発

GitHub PagesとActionsで公開しています。公開釣果の収集予定は6時間ごと、日本時間03:17・09:17・15:17・21:17です。GitHubの待ち行列で開始が遅れる場合があります。失敗時は過去の成功データを保持します。海況は毎時7分に11公開地点（10海域＋マリーナ）の予報を収集します。潮汐は近日分と公開釣果の日付・隣接日をキャッシュします。私有ポイントの座標や釣果は外部APIに送信しません。範囲内の私有点には近隣の公開予報を端末内で選び、対象範囲外は取得なしと表示します。個人・非商用利用を前提としています。

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/*.cjs
python3 scripts/build_site.py
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザの自動チェックにはPlaywrightとChromium／WebKitを使用します。必要なら`SEABORNIA_PLAYWRIGHT`にインストール先を設定し、サーバー起動後に実行します。

```sh
node scripts/check_browser.cjs
node scripts/check_resilience.cjs
node scripts/check_conditions.cjs
```

チェックは一時ブラウザの合成データだけを使用します。`/tmp/seabornia-browser-qa`に検証結果・スクリーンショットを出力します。実機iPhoneでのSafari、ホーム画面、GPS権限、VoiceOverの操作確認は別途必要です。

設計・確認状況は`QA.md`、開発の続きは`PROGRESS.md`を参照してください。
